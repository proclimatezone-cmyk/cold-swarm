# Холодный Рой — Станция «Гелиос-7»
Браузерный хоррор-шутер (Three.js). Работает на iPhone, Android, ПК, Mac. Без сборки.

## Публикация на GitHub Pages (бесплатно)
1. github.com → New repository → имя `cold-swarm` → Public → Create.
2. «uploading an existing file» → перетащить все файлы из папки → Commit.
3. Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save.
4. Через 1–2 минуты: `https://<USERNAME>.github.io/cold-swarm/?p1=Отец&p2=Сын`
